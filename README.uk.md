# ШІ-помічник з налаштування автозвуку (Autosound Tuning Skill)

🇬🇧 [English](README.md) · 🇩🇪 [Deutsch](README.de.md) · 🇵🇱 [Polski](README.pl.md) · 🇺🇦 **Українська** · ❓ [FAQ](FAQ.uk.md) · 📘 [TCC quick guide (EN)](https://github.com/ayukhno/autosound-tcc/blob/main/docs/guide/QUICK-GUIDE.md)

**Простими словами:** Це твій особистий ШІ-майстер із налаштування автозвуку. Хочеш ідеальну звукову сцену та рівний тональний баланс, але графіки, фази й затримки здаються надто складними? Цей асистент візьме складну частину на себе. Він зчитує вимірювання з мікрофона та крок за кроком веде тебе до ідеального звуку.

- **Ти вимірюєш — ШІ рахує:** Він працює разом із програмою REW, аналізує акустику твого салону та пропонує точні налаштування для EQ, кросоверів і часового вирівнювання.
- **Мінімум часу в машині:** Основні обчислення виконуються вдома за столом. У машині ти робиш лише початкові вимірювання, а потім повертаєшся вже з готовими цифрами, щоб послухати результат і крок за кроком зануритися в глибоке налаштування.
- **Нічого не записує у твій DSP — завантажуєш ти:** Асистент ніколи не чіпає твій процесор напряму. Він показує тобі цифри та графіки й готує EQ для імпорту: на Helix весь банк Full EQ завантажується через DSP PC-Tool за один крок, а для процесорів без імпорту файлів безкоштовний [REW-EQ-CopyPaste-Assistant](https://github.com/IvanBakhmutov/REW-EQ-CopyPaste-Assistant) вставляє його. Що саме потрапить усередину — вирішуєш ти.
- **Не звичайний чат:** Стан проєкту та всі налаштування зберігаються у файлах на твоєму диску, тому нічого не «забувається» між сесіями й ти завжди можеш відкотитися на крок назад.
- **Два ШІ, а вирішує твій слух:** один ШІ пропонує налаштування, другий — перевіряє їх. Перевірка є частиною методу; опціональним є лише автоматичний зв'язок між ними — без нього ти вставляєш пакет у будь-який ШІ-чат вручну. Головний суддя — твій слух: ти слухаєш і вирішуєш, а не просто погоджуєшся.
- **Працює з фактами:** ШІ не вгадує налаштування. Якщо вимірювання неправильні або їх недостатньо, перевірка це помітить і попросить зробити вимірювання заново — або ж свідомо продовжити далі, прийнявши ризик помилки.

## Що потрібно для старту

Застосунок встановлюється однією командою. З обладнання та підписок тобі знадобиться таке:

1. **Вимірювальний мікрофон** (наприклад, UMIK-1, або краще XLR-мікрофон зі звуковим інтерфейсом і фізичним loopback).
2. **Процесор (DSP)** у твоєму авто.
3. **Програма REW (Room EQ Wizard)** — потрібна **бета-версія** (поточна релізна збірка, V5.31.3 від липня 2024 року, взагалі не має API — перевір Help → About перед початком). Завантаж бета-збірку з [roomeqwizard.com/beta.html](https://www.roomeqwizard.com/beta.html). Після запуску REW перейди в *Preferences → API*, познач **Start the API when REW starts** і натисни **Start server**.
4. **Платна підписка на Claude (Pro або Max)** — Claude виконує основну важку роботу; це підтримуваний шлях, і застосунок створено саме під нього. Інші ШІ можуть керувати процесом через `omp` (встановлюється лише на твій запит) — на твій власний ризик.

*(Рекомендовано: безкоштовний акаунт GitHub, щоб зберігати резервну копію історії налаштувань у приватному репозиторії.)*

## Як встановити та запустити

**За замовчуванням інсталятор встановлює:** Claude Code, метод налаштування з бібліотеками Python, необхідними для його інструментів, десктопний застосунок **Autosound TCC** та Gemini-рев'юера (`agy`). Це займає 10–20 хвилин. Залежно від твоєї системи, інші інсталятори можуть запитувати дозвіл у процесі — це нормально (деталі у FAQ).

**macOS** — відкрий Terminal (⌘-Пробіл, введи «terminal», Enter) і встав:
```sh
curl -fsSL https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.sh | bash
```

**Windows** — відкрий PowerShell (Пуск, введи «powershell», Enter) і встав:
```powershell
irm https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.ps1 | iex
```
*(Версія в адресі фіксує сам інсталятор; він завжди встановлює найновіший реліз.)*

**Опції:**

| Що робить | macOS | Windows |
|---|---|---|
| моделі, відмінні від Claude, через `omp` | `--with-omp` | `-WithOmp` |
| резервна копія проєкту на GitHub (приватний репозиторій; ключі туди не потрапляють) | `--github` | `-GitHub` |
| метод без застосунку (тільки термінал) | `--terminal` | `-Terminal` |
| показати план і нічого не змінювати | `--dry-run` | `-DryRun` |

З опціями — наприклад, `omp` та резервне копіювання на GitHub — на macOS:
```sh
curl -fsSL https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.sh | bash -s -- --with-omp --github
```
і на Windows двома рядками:
```powershell
$i = irm https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.ps1
& ([scriptblock]::Create($i)) -WithOmp -GitHub
```

**Уже в Claude Code?** Метод також встановлюється як плагін:
```sh
claude plugin marketplace add ayukhno/autosound-tuning-skill
claude plugin install autosound-tuning
```
Плагін додає лише файли методу: під час першої сесії введи **`/autosound-tuning:setup`** — це перевірить плагін на відповідність підписаному релізу та встановить усе інше. Десктопний застосунок TCC у такий спосіб не додається; встанови його за допомогою `/autosound-tuning:setup app` (або `/autosound-tuning:install-tcc`).

**Після встановлення:**
1. Останній крок інсталятора виконує вхід: Claude, потім Gemini-рев'юер (`agy`), і GitHub, якщо ти його вибрав.
2. Відкрий застосунок **Autosound TCC** зі свого робочого столу.
3. Створи порожню папку для свого авто (наприклад, `MyCarTuning`) і вибери її в застосунку з **AI main: Claude Opus (SDK)** та **AI critic: Gemini Pro (High)** — або **Gemini Flash (High)**, якщо Pro тобі не пропонується.
4. **Важливо:** тримай effort у Claude Opus на рівні `xhigh` або вище (типове значення; `max` для складних кроків).
5. Напиши в чаті застосунку: **"tune a new car from scratch"**. ШІ почне ставити запитання та вести тебе за руку.

Віддаєш перевагу спілкуванню з ШІ в терміналі? Це теж працює, і багатьом так зручніше: тримай TCC поруч у **Control mode**, де ти бачиш і контролюєш кожен параметр під час роботи сесії ([довідник TCC](https://github.com/ayukhno/autosound-tcc/blob/main/docs/guide/REFERENCE.md#control-mode), [FAQ](FAQ.uk.md#control-mode-сесія-в-терміналі)).

▶ **Цільові криві:** метод постачається з власною кривою для змагань — **SQ-Comp-Ref**. **[Target Curve Visualizer](https://ayukhno.github.io/autosound-tuning-skill/_curve-visualizer.html?lang=uk)** аналізує та порівнює криві пліч-о-пліч — SQ-Comp-Ref, твої власні з REW або стандартні з [Nono Tuning Tool](https://nonotuningtool.com) — і зберігає обрану. Як вибрати криву: [керівництво з цільових кривих](skills/autosound-tuning/references/patterns/target-curves/target_curves_guide.md).

## Як виглядає процес налаштування

1. **Підготовка вдома:** Ти розповідаєш ШІ про свою систему (які динаміки, який процесор).
2. **Вимірювання в машині (один раз):** із захисними фільтрами на DSP ти записуєш кожен динамік окремо за одну сесію; застосунок TCC крок за кроком веде тебе через цей процес. Далі налаштування розраховується за робочим столом.
3. **Математика за столом:** Ти сидиш за комп'ютером (без машини поруч). ШІ аналізує вимірювання, стикує сабвуфер із мідбасом, вирівнює звукову сцену та розраховує EQ. За столом результати лише прогнозуються; машина потім їх перевіряє.
4. **Знову в машині — перевірка, корекція, тонке налаштування:** введи цифри в DSP, перевір їх кількома вимірюваннями та на слух і скоригуй те, що відхиляється. Далі йде тонке налаштування, яке найкраще робити в машині з найпотужнішою моделлю (на сьогодні це Claude Fable): ти розповідаєш ШІ, що чуєш, і що кращого звучання ти прагнеш, то більше ітерацій знадобиться. Працювати за столом теж можна — модель і метод адаптуються.

## Зворотний зв'язок, підтримка та конфіденційність

**Конфіденційність:** Скіл навчається на кожному налаштуванні та, лише за твоєю прямою згодою, надсилає узагальнений досвід до спільної бази знань. Він ніколи не збирає персональні дані й ніколи не надсилає повні вимірювання.

**Проблеми та баги:**
- Якщо щось не так із самою логікою налаштування: [відкрий issue на GitHub (autosound-tuning-skill)](https://github.com/ayukhno/autosound-tuning-skill/issues/new/choose).
- Якщо проблема стосується графічного інтерфейсу (Autosound TCC) — напиши в [репозиторій застосунку TCC](https://github.com/ayukhno/autosound-tcc/issues/new/choose).
- Немає акаунту GitHub? Попроси в сесії ("report a bug") або скористайся вікном звіту в TCC: твій звіт надійде автору через Google Form замість цього — тільки текстом.
