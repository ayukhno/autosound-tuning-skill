# ШІ-помічник з налаштування автозвуку (Autosound Tuning Skill)

🇬🇧 [English](README.md) · 🇩🇪 [Deutsch](README.de.md) · 🇵🇱 [Polski](README.pl.md) · 🇺🇦 **Українська** · ❓ [FAQ](FAQ.uk.md) · 📘 [TCC guide (EN)](https://github.com/ayukhno/autosound-tcc/blob/main/docs/guide/QUICK-GUIDE.md) · <img src="assets/icons/roadmap.svg" width="14" height="14" valign="middle" alt="Roadmap" /> [Roadmap (EN)](ROADMAP.md)

**Простими словами:** це твій особистий ШІ-майстер із налаштування автозвуку. Хочеш бездоганну сцену та рівний тональний баланс, але графіки, фази й затримки здаються занадто складними? Цей асистент візьме на себе найважчу частину. Він зчитує вимірювання твого мікрофона та крок за кроком веде тебе до ідеального звучання.

- **Ти вимірюєш — ШІ рахує:** він працює в парі з програмою REW, аналізує акустику твого салону та пропонує точні налаштування для EQ, кросоверів і часових затримок.
- **Мінімум часу в авто:** основні розрахунки відбуваються за робочим столом удома. В авто ти робиш лише початкові вимірювання, а потім повертаєшся з готовими значеннями, щоб послухати результат і крок за кроком зануритися в глибоке налаштування.
- **Нічого не записує в DSP — завантажуєш ти:** асистент ніколи не чіпає твій процесор напряму. Він показує тобі цифри й графіки та готує EQ до імпорту: на Helix весь банк Full EQ завантажується через DSP PC-Tool за один крок, а для процесорів без імпорту файлів безкоштовний [REW-EQ-CopyPaste-Assistant](https://github.com/IvanBakhmutov/REW-EQ-CopyPaste-Assistant) вставляє його автоматично. Ти сам вирішуєш, що туди потрапить.
- **Не звичайний чат:** стан проєкту та всі налаштування зберігаються у файлах на твоєму диску, тому нічого не «забувається» між сесіями, і ти завжди можеш відкотитися на крок назад.
- **Два ШІ, а вирішує твій слух:** один ШІ пропонує налаштування, другий — перевіряє їх. Перевірка є частиною методу; опціональним є лише автоматичний зв'язок між ними — без нього ти вставляєш пакет у будь-який ШІ-чат вручну. Головний суддя — твій слух: ти слухаєш і вирішуєш, а не просто погоджуєшся.
- **Працює з фактами:** ШІ не вгадує налаштування. Якщо вимірювання помилкові або їх недостатньо, перевірка це помітить і попросить переміряти — або ж продовжити свідомо, беручи ризик помилки на себе.

## Що потрібно для початку

Застосунок встановлюється однією командою. Із заліза та підписок тобі знадобиться таке:

1. **Вимірювальний мікрофон** (наприклад, UMIK-1 або краще XLR-мікрофон з аудіоінтерфейсом і фізичним loopback).
2. **Процесор (DSP)** у твоєму авто.
3. **Програма REW (Room EQ Wizard)** — обов'язково потрібна **beta-версія** (поточна релізна збірка, V5.31.3 від липня 2024 року, взагалі не має API — перевір Help → About перед початком). Завантаж beta-збірку з [roomeqwizard.com/beta.html](https://www.roomeqwizard.com/beta.html). Після запуску REW перейди до *Preferences → API*, познач **Start the API when REW starts** і натисни **Start server**.
4. **Платна підписка Claude (Pro або Max)** — Claude бере на себе основну роботу; це офіційно підтримуваний шлях, і застосунок створено саме під нього. Інші ШІ можуть вести процес через `omp` (встановлюється лише за твоїм запитом) — на твій власний ризик.

*(Рекомендовано: безкоштовний акаунт GitHub, щоб зберігати резервну копію історії налаштувань у приватному репозиторії.)*

## Як встановити та запустити

**За замовчуванням інсталятор встановлює:** Claude Code, метод налаштування разом із бібліотеками Python, потрібними для його інструментів, десктопний застосунок **Autosound TCC** та Gemini-рев'юера (`agy`). Це займає 10–20 хвилин. Залежно від твоєї системи інші інсталятори можуть запитувати дозволи під час встановлення — це нормально (деталі у FAQ).

**macOS** — відкрий Terminal (⌘-Пробіл, введи "terminal", Enter) і встав:
```sh
curl -fsSL https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.sh | bash
```

**Windows** — відкрий PowerShell (Пуск, введи "powershell", Enter) і встав:
```powershell
irm https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.ps1 | iex
```
*(Версія в адресі фіксує лише сам інсталятор; він завжди встановлює найновіший реліз.)*

**Опції:**

| Що робить | macOS | Windows |
|---|---|---|
| інші моделі, окрім Claude, через `omp` | `--with-omp` | `-WithOmp` |
| резервна копія проєкту на GitHub (приватний репозиторій; ключі туди не потрапляють) | `--github` | `-GitHub` |
| метод без застосунку (тільки термінал) | `--terminal` | `-Terminal` |
| показати план і нічого не змінювати | `--dry-run` | `-DryRun` |

З опціями — наприклад, `omp` та резервною копією на GitHub — на macOS:
```sh
curl -fsSL https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.sh | bash -s -- --with-omp --github
```
а на Windows двома рядками:
```powershell
$i = irm https://raw.githubusercontent.com/ayukhno/autosound-tuning-skill/v3.0.66/install.ps1
& ([scriptblock]::Create($i)) -WithOmp -GitHub
```

**Вже у Claude Code?** Метод також можна встановити як плагін:
```sh
claude plugin marketplace add ayukhno/autosound-tuning-skill
claude plugin install autosound-tuning
```
Плагін додає лише файли методу: під час першої сесії введи **`/autosound-tuning:setup`** — він звірить плагін із підписаним релізом і встановить решту. Десктопний застосунок TCC у такий спосіб не встановлюється; додай його за допомогою `/autosound-tuning:setup app` (або `/autosound-tuning:install-tcc`).

**Після встановлення:**
1. Останній крок інсталятора виконує авторизацію: Claude, потім Gemini-рев'юер (`agy`), і GitHub, якщо ти його вибрав.
2. Відкрий застосунок **Autosound TCC** зі свого робочого столу.
3. Створи порожню папку для свого авто (наприклад, `MyCarTuning`) та вибери її в застосунку, вказавши **AI main: Claude Opus (SDK)** та **AI critic: Gemini Pro (High)** — або **Gemini Flash (High)**, якщо Pro тобі не пропонується.
4. **Важливо:** тримай рівень effort для Claude Opus на `xhigh` або вище (за замовчуванням; `max` для складних кроків).
5. Напиши в чаті застосунку: **"tune a new car from scratch"**. ШІ почне ставити запитання та поведе тебе за руку.

▶ **Цільові криві:** метод постачається з власною змагальною кривою — **SQ-Comp-Ref**. **[Target Curve Visualizer](https://ayukhno.github.io/autosound-tuning-skill/_curve-visualizer.html?lang=uk)** аналізує та порівнює криві пліч-о-пліч — SQ-Comp-Ref, твої власні з REW або стандартні з [Nono Tuning Tool](https://nonotuningtool.com) — і зберігає ту, яку ти обереш. Як вибрати криву: [керівництво з цільових кривих](skills/autosound-tuning/references/patterns/target-curves/target_curves_guide.md).

## Як виглядає процес налаштування

1. **Підготовка вдома:** ти розповідаєш ШІ про свою систему (які динаміки, який процесор).
2. **Вимірювання в авто (один раз):** із захисними фільтрами на DSP ти заміряєш кожен динамік окремо за одну сесію; застосунок TCC веде тебе крок за кроком. Далі налаштування проєктується вже за робочим столом.
3. **Математика за столом:** ти сидиш за комп'ютером (без авто поруч). ШІ аналізує вимірювання, зводить сабвуфер із мідбасом, вирівнює сцену та розраховує EQ. За столом результати лише прогнозуються; в авто вони потім верифікуються.
4. **Знову в авто — перевірка, корекція, точне доведення:** внеси значення в DSP, перевір їх кількома вимірюваннями та на слух і підкоригуй відхилення. Після цього починається тонке налаштування, яке найкраще робити безпосередньо в авто з найпотужнішою моделлю (на сьогодні це Claude Fable): ти розповідаєш ШІ, що саме чуєш, і що кращого звучання ти прагнеш досягти, то більше раундів знадобиться. Працювати за столом також можливо — модель і метод адаптуються.

## Зворотний зв'язок, підтримка та приватність

**Приватність:** skill навчається на кожному налаштуванні й лише за твоєї прямої згоди надсилає узагальнені висновки до спільної бази знань. Він ніколи не збирає персональні дані та ніколи не надсилає повні вимірювання.

**Проблеми та помилки:**
- Якщо щось не так із самою логікою налаштування: [відкрий issue на GitHub (autosound-tuning-skill)](https://github.com/ayukhno/autosound-tuning-skill/issues/new/choose).
- Якщо проблема стосується графічного інтерфейсу (Autosound TCC) — пиши в [репозиторій застосунку TCC](https://github.com/ayukhno/autosound-tcc/issues/new/choose).
- Немає акаунта GitHub? Попроси під час сесії ("report a bug") або скористайся вікном повідомлення про проблему в TCC: твій звіт надійде автору через Google Form — виключно текстом.
