## 2. Ніде не написано, як додати ключ для Antigravity (Windows і Mac)

**Відкладено до 3.1.0 → [#28](https://github.com/ayukhno/autosound-tuning-skill/issues/28).**

- **Що видно:** у документації скіла нема інструкції, як прописати API-ключ для каналу
  `agy` (Antigravity) ні на Windows, ні на Mac.
- **Що знайшов користувач для Windows** (PowerShell, змінна для поточного користувача):
  ```powershell
  [System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "ваш_ключ_сюди", "User")
  ```
- **Відкрите:** назва змінної в знайденому рядку — `OPENAI_API_KEY`. Яку змінну читає
  саме `agy`, не звірено. Для Mac рядка ще нема.
